# THE HIVE — PS1-style browser game
Fan-made homage to the queen's-lair finale of *Aliens* (1986). Original low-poly art, WebAudio chiptune and paraphrased text; no film assets.
Open `index.html` (static, no build). Desktop: WASD move, mouse aim, click/Space fire, Q/E/Tab swap, click/Enter skip cutscene. Phone: left thumb stick, right thumb drag to aim, FIRE/SWAP buttons.
Debug: `?fps`, `?auto` (autopilot), `?touch`. Test: `node tests/test.js phone shots_phone`.
